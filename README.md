# 学祭ピザ屋 呼び出し＆注文管理システム 🍕

学祭のピザ屋模擬店向けに開発された、リアルタイム注文・呼び出しベルシステムです。
注文から焼き上がりまでの待ち時間に、お客さんがブースを離れていてもスマホへ確実に焼き上がりを通知します。

---

## 💡 特徴・機能

1. **アプリ・個人情報不要のWeb呼び出しベル**
   - お客さんは番号札のQRコードをカメラで読み取るだけ。
   - 焼き上がると、スマホ画面が点滅し、音とバイブレーションで通知します。

2. **直感的なスタッフ管理画面 (ノートPC用)**
   - 整理番号のワンクリック選択
   - 4種類 × 2サイズ（ピース / ホール）計8種の注文登録
   - 合計金額の自動計算
   - 「焼き中 🔥」→「焼き上がり！呼出 📢」→「受取完了 ✅」のカンバン方式
   - 累計注文件数・本日売上の自動集計

3. **メニュー・価格の即時調整**
   - マルゲリータ、マリナーラ、チョコマシュマロ、リンゴピザのピース価格・ホール価格を、画面上でいつでも変更・保存できます。

4. **店頭モニター画面 (呼出番号の大型掲示)**
   - 余ったタブレットや、ノートPCの画面をお客さん側に向けることで、現在呼び出し中の番号を特大表示できます。

5. **番号札＆QRコード一括印刷シート**
   - 1番〜30番（設定で変更可能）の番号札＆QRコードをA4用紙に綺麗に並べてプレビュー・一発印刷できます。

## 🚀 起動方法

### 簡単起動 (Windows)
フォルダ内の `start.bat` をダブルクリックするだけです。
自動で依存パッケージを確認し、ブラウザで管理画面が開きます。

### 手動起動 (コマンドライン)
```bash
cd pizza-call-system
python -m pip install -r requirements.txt
python main.py
```

起動後、ブラウザで以下のURLを開きます：
- **スタッフ管理画面**: `http://localhost:8000/`
- **店頭モニター画面**: `http://localhost:8000/display`
- **番号札＆QRコード印刷シート**: `http://localhost:8000/cards`
- **お客さんスマホ画面（テスト用）**: `http://localhost:8000/call?num=1`

## 📱 学祭当日、お客さんのスマホからアクセスさせる方法

ノートPCで動かしているシステムをお客さんのスマホ（4G/5G回線）から開くには、主に以下の2つの方法があります。

### おすすめ方法①: 無料のトンネルツールを使う（最も確実）
ノートPCをテザリングやWi-Fiに繋ぎ、以下のいずれかのツールでインターネット上に公開URLを発行します。

- **Cloudflare Tunnel (cloudflared)**:
  `cloudflared tunnel --url http://localhost:8000` を実行すると `https://xxx.trycloudflare.com` という公開URLが即座に発行されます。
- **localtunnel**:
  `npx localtunnel --port 8000`

※ 公開URLが発行されたら、`/cards`（番号札印刷シート）の「QRコードのURL基点」欄にそのURLを入力して印刷すれば、お客さんのスマホから直接アクセスできます！

### おすすめ方法②: クラウド（Render / Railway / Glitch等）にデプロイ
GitHubリポジトリにアップロードし、Renderなどの無料ホスティングにデプロイしておけば、当日ノートPC側はブラウザを開くだけで運用できます。

## 📋 学祭当日のオペレーション手順

1. **事前準備**:
   - `/cards` 画面を開き、1番〜30番（想定される最大待ち枚数分）をA4用紙に印刷。
   - ハサミやカッターで切り離し、100円ショップのラミネートフィルムやカードスタンドに入れておく。
2. **受付**:
   - 注文を受けたら、番号札（例: 05番）をお客さんに渡す。
   - ノートPCの「新規注文登録」で「05番」と商品を選んで確定。
3. **客の行動**:
   - お客さんがスマホのカメラで番号札のQRコードを読み取る。
   - 画面の「通知音をONにする」をタップしてもらう。
4. **焼き上がり**:
   - 厨房でピザが焼けたら、PCの「05番 焼き上がり！(呼出)」をクリック。
   - お客さんのスマホでアラームとバイブが作動し、店頭モニターにも大きく05番が表示される。
5. **受け渡し**:
   - お客さんがブースに来たら、番号札と引き換えにピザを渡す。
   - PCの「受取完了」をクリック。番号札は回収して次の注文で使い回す。
